# 综合新闻报告

综合新闻报告位于创业雷达的上游：它先归纳宏观经济、政策监管、产业公司、科技产品和消费社会变化，再由创业雷达判断哪些变化值得转化为创业验证方向。

## 证据状态

- **多源印证**：至少两个独立发布者支持同一事件；BBC 的不同栏目、同一通讯社转载等别名会归并，避免形成伪多源。
- **官方/一手**：政府、机构、交易所、公司或项目的原始发布，可以单独进入报告，但仍提示后续观察。
- **单源观察**：只有一家专业媒体支持，自动降为低可信度；可以阅读和获得线索，但不能当作已经确认的趋势。
- 单个 Reddit、Hacker News 等社区材料不会成为新闻事件，只能作为后续创业灵感材料。

## 当前来源

当前配置优先覆盖新华社、联合早报、澎湃新闻、BBC、CNN 和朝日新闻，同时采集中国政府及公共机构信息。BBC 使用官方 RSS；其他无稳定开放 RSS 的媒体通过限定官网域名与发布者白名单的 Google News 查询发现，只保留标题、摘要、发布时间和原文链接。

## 生成与输出

```bash
uv run news-digest --hours 24
```

每次运行产生三类文件：

- `data/news/news-digest-YYYY-MM-DD.json`：结构化数据；
- `data/news/news-digest-YYYY-MM-DD.md`：本地 Markdown 报告；
- `docs/_posts/YYYY-MM-DD-news-digest.md`：GitHub Pages 页面。

每日工作流会先生成综合新闻报告，再运行创业雷达，最后统一部署到 `gh-pages`。
